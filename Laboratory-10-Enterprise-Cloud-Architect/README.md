# CCM101 Cloud Computing Final
a secure, automated WordPress + MySQL stack on Ubuntu Server in VirtualBox.
# Stack 
WordPress, MySQL 8.0, Docker Compose, UFW, Bash + cron.
# Files in this folder
one line each for docker-compose.yml, automation-script.sh, .env.example, architecture-diagram.png, operational-manual.md, final-reflection.md.
Quick start: cp .env.example .env, edit the passwords, then docker compose up -d. This is the fast path you’ll use on KillerCoda.
# Access 
http://localhost:8080 (host 8080 forwarded to guest 80).
