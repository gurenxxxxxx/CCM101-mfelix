During Mission 1, my understanding was limited to basic system concepts, high level cloud architecture, and rudimentary system commands. I am able to create services by putting together Docker containers with Docker Compose, write automation scripts, configure system firewalls (ufw) and troubleshoot any low level service or dependency issues. The first time you come across edge cases, like unexpected errors or something getting stuck, you can create the documentation so that everyone else knows what to do in that situation and turn a one-time fix into part of the institutional knowledge. A true Architect will build systems that anyone on the team can use, understand, and easily fix without friction.
